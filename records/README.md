# 历史记录档案

本目录保存历史工程证据的脱敏副本，不能作为当前账户状态或收益展示。

- [完整索引](manifest.json)：公开文件、保留在本地的原始文件、日志行数和事件计数。
- [报告](reports/)：行情筛选、服务小时诊断和其他历史 Markdown 报告。
- [自动化运行笔记一](automation/run-notes-1.md)和[笔记二](automation/run-notes-2.md)：原有两处记录分别保留，不伪造统一时间线。
- [复盘](../docs/postmortems/)：交易复盘和模板。

`[VALUE]`、`[PRIVATE_PATH]`、`[PRIVATE_IP]`、`[PRIVATE_ID]` 和 `[PRIVATE_LINK]` 是主动移除的信息，不是零值。日期以源记录为准；导出过程中没有重新核实源记录结论。早期“无挂单”等表述的证据边界见[实现限制](../docs/implementation-status.md)。
