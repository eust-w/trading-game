# 入场前检查清单

- [ ] 当前是否已有仓位？
- [ ] 本次交易是否符合只持有一个主要方向的原则？
- [ ] 入场理由是否来自计划，而不是临时追涨杀跌？
- [ ] 止损价是否已经明确？
- [ ] 止损后亏损是否在可接受范围内？
- [ ] 是否存在重大消息、数据公布、解锁或交易所维护？
- [ ] 成交量是否支持当前方向？
- [ ] 资金费率是否过度拥挤？
- [ ] 如果连续亏损，今天是否应该停止交易？
- [ ] 当前 symbol 今天是否已经连续两次亏损？如果是，停止交易该 symbol。
- [ ] 当前是否属于亏损后补仓？如果是，除非入场前计划已写明，否则禁止。
- [ ] 15m/1h 是否出现异常长针、放量反转或 ATR 急速放大？如果是，仓位降到常规 20% 以下或跳过。
- [ ] 这笔交易扣除两边手续费、滑点和资金费后，风险收益比是否仍然成立？
- [ ] 该 symbol 最近是否出现过 `INSURANCE_CLEAR` 或接近强平事件？如果是，先复盘，不交易。
