# 交易游戏原始设计

以下整理自项目最初的策略要求，删除了凭据。它是研究目标，不代表当前源码全部实现，也不构成实盘收益或安全承诺。

## 范围与总原则

仅 Binance USD-M / USDT-M 永续合约。排除现货、币本位、理财、借贷和账户划转。凭据通过环境变量或本机私密文件读取。

1. 同时最多一个合约仓位，不持有多个币种。
2. 已有仓位必须先评估持有、减仓、平仓或换仓。
3. 新机会必须在扣除手续费、滑点、资金费率、价差及换仓摩擦后明显优于旧仓位，才考虑换仓。
4. 不为轻微信号变化频繁换仓；强度接近时保持。
5. 持仓必须有有效止损。缺失时优先补足。
6. 趋势不清晰、成交量不足、风险收益比不足或强平风险过高时不新开仓。
7. 单次运行只执行一个主要动作：保持、补充保护、调整保护、减仓、平仓、换仓、开新仓或不交易。

## 账户检查

每次先检查总权益、可用保证金、合约、方向、数量、开仓均价、杠杆、保证金模式、未实现盈亏、标记价格、强平价及距离、仓位名义价值占权益比例、保证金占用。

同时查询普通挂单和条件单：止损是否存在、有效且覆盖风险；止盈是否覆盖全部仓位；是否有过期、重复、多余或相互冲突的条件单。普通 `openOrders` 返回空数组不能独立证明没有条件保护单。

## 持仓判断

结合 15m、1h、4h 趋势，EMA20/EMA50 排列与斜率，关键均线突破或跌破，RSI 极端或背离，ATR 变化、成交额变化、浮盈浮亏、止损止盈距离、强平距离、资金费率及剩余风险收益比。

持仓仍有效时保持，仅在必要时调整保护；风险升高优先考虑减仓或平仓。结构失效且新机会明显更好时才研究换仓。

## 市场扫描

扫描主流或高成交额、流动性好的 U 本位永续合约，排除低流动性、异常插针、盘口过薄及短时异常拉盘。

候选因子包括三周期趋势、EMA 排列及斜率、RSI、ATR、24h 成交额、近期放量或缩量、结构突破、震荡区间、急涨急跌、大周期一致性、追涨追空风险、止损距离、止盈空间、资金费率、价差及滑点。

最多选择一个候选；没有明确机会时不交易。目标毛风险收益比至少 1:1.8，优先 1:2 以上，并另行核算扣除成本后的净风险收益比。

## 仓位预算

- 新仓最多使用可用保证金的 50%，不得满仓。
- 风险偏高、强平过近、ATR 过大、止损太宽或信号较弱时，降低至可用保证金的 10%–30%，或不开仓。
- 常规调整最多处理现有仓位的 50%；明确强制平仓条件例外。
- 不得加仓摊平亏损或盲目补仓。
- 保证金、杠杆后的名义仓位及最大止损损失分别计算，不能混为一个比例。

开仓前列明入场价、止损价、分档止盈价、数量、预计最大亏损、收益、毛风险收益比、双边手续费、滑点、价差、资金费影响及净风险收益比。

## 止损止盈

止损共同依据结构位、ATR 和账户风险预算确定，避开正常波动，但不可通过无限放宽止损掩盖亏损。

| 档位 | 原始设想 |
|---|---|
| 第一档 | 约 1R，止盈 30%–40% |
| 第二档 | 约 1.8R–2R，止盈 30%–40% |
| 第三档 | 趋势延续目标，退出剩余数量 |

第一档成交后可以研究将剩余止损移至成本或微利位置。最终必须验证各档数量之和覆盖实际仓位。

保持时不下单；缺失止损优先补充；止损太远重新评估；止盈不足补全方案。平仓后撤销无效旧保护单。原始换仓流程是退出旧仓、清理旧单、建立新仓并立即保护；这只是需求描述，非原子执行保证。

## 换仓的全部必要条件

1. 当前结构明显走弱，或剩余风险收益比已经恶化。
2. 新标的 1h 和 4h 方向更明确。
3. 新止损位置更明确。
4. 新的净风险收益比明显更高。
5. 扣除旧仓退出和新仓进入的全部摩擦后仍有优势。
6. 新机会不是追涨追空。
7. 换仓后账户整体风险不增加。

任一条件缺失就不换仓。当前记录不应被倒推成具有这些计算的完整证据。

## 报告要求

每轮给出账户概况和低/中/高风险等级；当前持仓及保护判断；唯一候选、方向、多周期支持和风险因素；是否值得换仓；最终唯一动作。

执行时记录实际动作、价格、数量、比例、止损、各档止盈、预计损失收益、手续费滑点及净风险收益比。未执行时说明原因、主要风险及下一次观察条件。账户或关键保护状态未知时明确标注未知，不推断安全。
