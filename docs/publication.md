# 公开发布范围

整理日期：2026-10-25。来源为用户持有的 Alpha Vault 工作目录及“交易游戏”自动化运行笔记。源目录没有已有提交；公开版使用全新 Git 历史，私有目录及远端不改变。

## 收录

- 原有 12 个 Python 实现文件和 7 个测试文件，保持模块布局。
- 方法论、研究模板、操作手册、复盘文档，以及重新整理的最初策略要求。
- 281 份历史 Markdown 报告和 2 份自动化运行笔记的脱敏版本。
- 153 个原始数据/日志文件的清单与可用的行数、事件类型汇总。
- 依赖定义、测试入口、公开内容扫描器、许可证及发布边界说明。

`records/manifest.json` 记录每个来源的公开位置或保留原因。没有声称包含无法读取的外部分享正文，也没有导出整段对话或私人文档库。

## 脱敏

原始 API 密钥、秘密、账户原始流水、成交明细、订单标识、私有文件系统路径、网络 IP、私人分享链接和服务进程标识不公开。源码使用空白凭据示例和文档 IP；历史文本中的数量、金额、价格及其他数字统一替换为 `[VALUE]`，日期和定性结论保留。部分指标、版本或命令数字也会被保守遮蔽。

历史 Markdown 是阅读档案，不是可复制执行的操作手册；被遮蔽的代码片段不能直接运行。最新操作入口以 README 和当前源码为准。

原始 JSON/JSONL/CSV/日志不上传。对 JSONL 仅公开记录数量、解析失败数量和受限的事件类型计数；计数不构成对成交、盈利或账户风险的证明。公开清单中的相对文件名仅用于索引本地记录，不包含文件内容。

## 验证范围

发布验证包含离线测试、Python 编译、CLI 帮助、依赖漏洞审计、文件与 Git 历史密钥扫描、私有路径检查、远端提交一致性及匿名可访问性。验证过程不提供私人 API 凭据，不启动实盘服务，也不执行交易或撤单。
