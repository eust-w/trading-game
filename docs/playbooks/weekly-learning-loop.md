# 每周交易学习闭环

## 目标

每周把真实交易记录转化成下周能执行的规则，而不是只写情绪化总结。

## 输入

- `docs/postmortems/binance-usdm-30d-review.md`
- 当周 Binance USD-M income 和 userTrades 导出
- 亏损前 5 名 symbol
- 盈利前 5 名 symbol
- 盘中截图和手写理由

## 步骤

### 1. 分清账户流水和交易盈亏

先排除 `TRANSFER`、`AUTO_EXCHANGE` 等账户级非交易流水。每周重点看分币种交易净额。

输出：

- 当周交易净额
- 手续费
- 资金费
- `INSURANCE_CLEAR`
- 最大亏损 symbol
- 最大盈利 symbol

### 2. 先复盘亏损集中币

按亏损金额排序，只看前 5 名。

每个 symbol 回答：

- 第一次入场理由是什么？
- 第一次亏损后是否继续交易同一 symbol？
- 是否补仓、反复进出或移动止损？
- 15m/1h 是否出现异常波动？
- 是否违反了“连续两次亏损暂停”？

### 3. 再提炼盈利模式

按盈利金额排序，只看前 5 名。

每个 symbol 回答：

- 盈利来自哪种结构？
- 是否可复用？
- 是否依赖行情特殊性？
- 手续费占毛利润比例是否健康？
- 有没有同类亏损样本反证？

### 4. 固化一条规则

每周只新增或修改一条最重要的规则。

规则必须满足：

- 可以在入场前判断。
- 可以用数据或截图复核。
- 不依赖事后解释。
- 能减少大亏或保留大赚。

### 5. 写入下周检查清单

把规则同步到：

```text
ops/checklists/pre-trade.md
```

如果规则需要脚本检查，再同步到：

```text
quant/screeners/
```
